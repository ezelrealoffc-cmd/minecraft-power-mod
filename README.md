# minecraft-power-mod

Bu proje, Forge 1.20.1 için hazırlanmış örnek bir Minecraft modudur.

Özellikler:
- Özel item: "Power Core"
- Sağ tık ile kendini feda ederek ölüm etkisi
- Ölüm sonrası aynı konumda yeniden doğma
- Yeniden doğduğunda 2x buff (hasar + hareket + can)
- G tuşu ile 3 saniyeye kadar güç çekme
- Sağ tarafta güç çubuğu
- Z tuşu ile güçlü yumruk modu
- Şarjlı yumrukta knockback + yüksek hasar

Kurulum:
1. Java 17 kurulu olmalıdır.
2. Projeyi klonlayın.
3. `gradlew genIntellijRuns` veya `gradlew build` çalıştırın.
4. IDE içinde çalıştırma konfigürasyonu oluşturun.

Not:
Bu dosya, temel bir Forge mod prototipi olarak oluşturulmuştur. Modu tam olarak geliştirip test etmek için Minecraft geliştirme ortamı ve Forge kurulumları gereklidir.
